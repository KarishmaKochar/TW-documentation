
# Technical Writing – Course Documentation

## Introduction

This repository contains the documentation and practical work completed as part of my Technical Writing course.

During this course, I learned about different tools used for creating documents, preparing presentations, generating code documentation and managing projects. This repository brings together the topics I studied along with a few practical examples.

## Topics Covered

The repository covers the following six topics:

1. **LaTeX:** Document preparation, formatting, mathematical equations, tables and references.
2. **Beamer:** Creating presentations using frames, themes, blocks and columns.
3. **Doxygen:** Generating documentation from source code using comments and configuration files.
4. **Google Docs:** Document creation, formatting, sharing and real-time collaboration.
5. **Git:** Version control, repositories, commits, branching and merging.
6. **GitHub:** Repository hosting, remote operations and project collaboration.

## Practical Work

Along with the documentation, I have included:

- A sample presentation created using Beamer.
- A C++ calculator program demonstrating Doxygen documentation.
- A Doxyfile for generating code documentation.

## Tools Used

LaTeX, Beamer, Doxygen, Google Docs, Git, GitHub, C++ and Visual Studio Code.

## Learning Outcomes

Through this coursework, I gained practical knowledge of document preparation, presentation creation, code documentation and version control. I also learned how to organise project files and maintain a repository using Git and GitHub.

## Conclusion

This repository represents my learning and practical work throughout the Technical Writing course. It helped me understand the importance of proper documentation and gain hands-on experience with different tools used in technical writing.
