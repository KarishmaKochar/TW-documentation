
# Google Docs – Online Document Creation and Collaboration

## 1. Introduction
Google Docs is a free, web-based word-processing application provided by Google. It allows users to create, edit, format and share documents online.

Unlike traditional offline word processors, Google Docs stores documents in Google Drive and allows multiple users to work on the same document simultaneously.

## 2. Main Features

- **Document Creation:** Create new documents and edit existing ones.
- **Formatting:** Change fonts, font sizes, colours, alignment and spacing.
- **Collaboration:** Multiple users can edit a document at the same time.
- **Auto-Save:** Changes are automatically saved to Google Drive.
- **Comments:** Users can add comments and suggestions.
- **Version History:** Previous versions can be viewed and restored.
- **Sharing:** Documents can be shared through links or email invitations.

## 3. Formatting and Editing

Google Docs provides different formatting options to organise documents professionally.

Common formatting features include:

- Bold, italic and underline.
- Font style and font size.
- Text and highlight colours.
- Paragraph alignment.
- Bulleted and numbered lists.
- Headings and styles.
- Inserting tables, images, links and page numbers.

Headings are particularly useful for creating structured documents and automatically generating a table of contents.

## 4. Collaboration and Sharing

Google Docs supports real-time collaboration, allowing multiple users to work on a document together.

Documents can be shared using the **Share** option.

Common access permissions include:

- **Viewer:** Can only view the document.
- **Commenter:** Can view and add comments.
- **Editor:** Can make changes to the document.

This makes Google Docs useful for group assignments, team projects and collaborative academic work.

## 5. Comments and Suggesting Mode

The comment feature allows users to provide feedback without directly changing the document.

Suggesting mode allows collaborators to propose edits that can later be accepted or rejected by the document owner.

These features make reviewing and editing documents easier.

## 6. Version History

Version History allows users to view earlier versions of a document and identify changes made over time.

Users can access it through:

**File → Version history → See version history**

It is useful for tracking edits and restoring previous content when necessary.

## 7. Importing and Exporting Documents

Google Docs supports different file formats.

Documents can be downloaded in formats such as:

- Microsoft Word (`.docx`)
- PDF (`.pdf`)
- Plain text (`.txt`)
- Rich Text Format (`.rtf`)

This makes it easier to share documents with people using different software.

## 8. Advantages and Applications

- Easy to access through a web browser.
- Supports automatic saving.
- Enables real-time group collaboration.
- Provides sharing and permission controls.
- Helps maintain document history.
- Useful for assignments, reports, notes and group projects.

## Conclusion

Through Google Docs, I learned how to create and format documents, collaborate with others, share files with different permissions, use comments and suggestions, access version history and export documents into different formats. It is an effective tool for academic and professional documentation.
